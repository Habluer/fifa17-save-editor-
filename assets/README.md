# Ícone do aplicativo

Conceito escolhido: número 17 com três controles de atributos, amarelo e preto, em um quadrado arredondado. Criado com a ferramenta integrada de geração de imagens e aprovado para este projeto; sem logotipos oficiais do FIFA/EA.

Prompt de finalização: preservar o conceito C; remover a legenda; manter o interior escuro e a parte externa transparente; centralizar o ícone, com número 17 destacado, borda amarela e três controles legíveis em tamanho pequeno.

`icon.png` é a imagem de origem. `icon.ico` contém imagens de 16, 24, 32, 48, 64, 128 e 256 pixels. Para reconstruir o ICO, execute `npm run build:icon`. A conversão usa o Electron já instalado no desenvolvimento, sem dependência adicional.
